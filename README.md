# 🎞️ POT Player Playlist Creator

This Chrome extension allows you to generate streamable playlists for **POT Player** and/or initiate bulk downloads from directory-style media websites.

---

## 📥 How to Install

> ⚠️ This extension is not available on the Chrome Web Store due to developer fees. You can install it manually by following the steps below:

1. 📦 **[Download the latest release](https://github.com/wskoly/PotPlayerStreamablePlaylistCreator/releases/latest "Latest Release")** from GitHub.
2. 🗂️ **Unzip the downloaded file** to a permanent location.  
   > 🔒 *Tip: Avoid placing it in a temporary folder like Downloads to prevent accidental deletion.*
3. 🌐 Open Chrome and go to `chrome://extensions`.
   - Or click the Extensions icon (🧩) → **Manage Extensions**  
   - Or go to **Chrome Menu → More Tools → Extensions**
4. 🛠️ **Enable Developer Mode** (toggle in the top-right corner).
5. 📁 Click **"Load unpacked"** and select the unzipped extension folder.

![Extension Installation](https://i.ibb.co/L9y9S3g/potpext1.png)

---

## ▶️ How to Use

1. 📌 **Pin the extension** to the Chrome toolbar for quick access.
2. 🌍 **Navigate to a web directory** containing media files (e.g., videos, audio).
3. 🧩 **Click the extension icon** in the toolbar.
4. 🎵 **Click "Download Playlist File"** to generate and download a `.m3u` playlist.  
   - Open this file in POT Player to stream media directly from the site.
5. 📥 Or click **"Download All Media Files"** to begin downloading all detected media files. *(Added in version 2)*
